# NETFLIX Clone


## 概要
NETFlixのCloneを作成
## デモ
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
## 機能一覧
Credential / Google アカウント / GitHub アカウント login  
アカウント登録後自動でプロフィール生成  
ログイン後ランダムに選ばれた映画、トレンドの映画リスト、マイリストを表示  
お気に入り（マイリストへの追加）  
作品詳細をモーダルで表示  
Play ボタンで再生
